# Pac-Man World 3 Enhanced (PC)

<img width="725" height="400" alt="PW3" src="https://github.com/user-attachments/assets/9f2b42d0-ddb2-42a0-9883-e7da246a0554" />

Fixes incorrect 60 FPS timing in the European PC version, resulting in smoother Pac-Man movement and animation, while also adding modern resolutions and removing obsolete launcher options.

## Features

- Fixes the uneven/jittery Pac-Man movement and animation timing in the European PC version at 60 FPS
- Removes obsolete launcher options
- Additional display resolutions:
  - 1920x1080
  - 2560x1440
  - 3840x2160

## Notes

The European PC version normally runs at 60 FPS, but Pac-Man's movement and animation timing are internally updated incorrectly, resulting in uneven and jittery movement.

## Compatibility

The USA version is not supported. This patch is designed specifically for the European PC version of Pac-Man World 3.
